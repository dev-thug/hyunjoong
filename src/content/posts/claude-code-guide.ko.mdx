# 터미널 위의 강력한 코딩 에이전트: Claude Code 완벽 가이드

최근 AI 코딩 도구의 트렌드가 단순한 자동완성을 넘어, 개발자의 의도를 이해하고 프로젝트 전체를 탐색하며 직접 코드를 수정하는 '에이전트' 형태로 진화하고 있습니다. 그 중심에 있는 **Claude Code**는 터미널 기반의 AI 코딩 도구로, 뛰어난 성능과 유연한 확장성을 자랑합니다.

오늘은 Claude Code의 기초부터 고급 활용 팁까지, 개발 생산성을 한 단계 높여줄 가이드를 정리해 드립니다.

---

## 1. 시작하기: 초기 설정 및 프로젝트 최적화

Claude Code를 가장 먼저 실행하면 프로젝트의 맥락을 파악하는 것이 중요합니다.

### 프로젝트 초기화 (`claude init`)
프로젝트 루트에서 `claude init`을 실행하면 `CLAUDE.MD` 파일이 생성됩니다. 이 파일은 Claude에게 프로젝트의 아키텍처, 코딩 규칙, 주요 기술 스택을 알려주는 '가이드북' 역할을 합니다.

```markdown
# CLAUDE.MD 예시
- Framework: Next.js 15 (App Router)
- Styling: Tailwind CSS
- Rules: 모든 컴포넌트는 함수형으로 작성, 'strict' 모드 준수
```

### 컨텍스트 참조 (`@` 기호)
작업 중 특정 파일이나 폴더를 참조하고 싶을 때는 `@` 기호를 사용하세요.
- `@파일명`: 해당 파일의 로직 분석 요청
- `@폴더명/`: 폴더 구조 분석 및 전체적인 맥락 파악

---

## 2. 에이전트(Subagent)와 스킬(Skills)

Claude Code의 진정한 강력함은 특정 분야에 특화된 '서브에이전트'와 '커스텀 스킬'을 정의할 수 있다는 점에 있습니다.

### 에이전트 설정
전문 지식을 가진 독립 작업자를 생성하여 복잡한 작업을 위임할 수 있습니다. `~/.claude/agents/`에 YAML 형식을 포함한 파일로 정의합니다.

```yaml
---
name: code-reviewer
description: 코드 품질 개선 제안 에이전트
tools: [read_file, search_files]
---
코드를 분석하고 가독성, 성능 관점에서 개선사항을 제안합니다.
```

### 스킬(Skills) 활용
자주 반복되는 지시사항이나 특정 프레임워크의 규칙을 스킬로 정의해두면 토큰을 효율적으로 사용하면서 일관된 결과를 얻을 수 있습니다. `~/.claude/skills/스킬이름/SKILL.md` 구조로 관리합니다.

---

## 3. MCP(Model Context Protocol): 외부 도구 연결

MCP를 통해 외부 도구(Sentry, GitHub 이슈 등)를 Claude Code에 직접 연결할 수 있습니다.

```bash
# HTTP 서버 추가 예시
claude mcp add --transport http sentry https://mcp.sentry.dev/mcp

# 사용 예시
"지난 24시간 동안 발생한 오류 ID abc123의 스택 추적을 보여줘"
```

---

## 4. 효율적인 작업을 위한 핵심 명령어 및 팁

### 세션 및 상태 관리
- `/clear`: 새로운 작업을 시작할 때 이전 컨텍스트를 지워 집중력을 높입니다. (강력 추천!)
- `/compact`: 긴 대화 내역을 압축하여 토큰 비용을 절약합니다.
- `/cost` & `/usage`: 현재까지의 비용과 사용량을 실시간으로 확인합니다.

### 권한 모드 활용
- `plan`: 분석만 수행 (읽기 전용)
- `acceptEdits`: 파일 수정을 자동으로 승인
- `bypassPermissions`: 모든 도구 사용 권한을 건너뛰고 빠르게 작업

### 생산성 단축키
- **Shift + Enter**: 개행 입력
- **Escape**: 현재 진행 중인 작업 중단
- **Shift + Tab**: 권한 모드(default/plan 등) 빠르게 전환
- **↑ 화살표**: 이전 명령 탐색

## 5. 마치며: 시스템 구축을 통한 레버리지

저는 항상 **"I don't just build software. I build leverage."**라고 말하곤 합니다. Claude Code는 단순히 코드를 대신 짜주는 도구가 아니라, 개발자의 아키텍처적 사고를 실제 코드로 빠르게 전환해주는 강력한 레버리지입니다.

`CLAUDE.MD`를 꼼꼼히 작성하고, 팀에 맞는 MCP 서버와 커스텀 스킬을 구축해 보세요. 반복적인 코딩 오버헤드가 줄어들고, 더 가치 있는 설계 고민에 집중할 수 있는 시간을 벌어줄 것입니다.
