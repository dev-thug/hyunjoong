# 터미널 위의 강력한 코딩 에이전트: Claude Code 완벽 가이드

최근 AI 코딩 도구는 단순히 코드를 채워주는 수준을 넘어, 프로젝트 전체의 맥락을 이해하고 직접 파일을 수정하며 이슈를 해결하는 '에이전트' 시대로 진입했습니다. 그 흐름의 선두에 있는 **Claude Code**는 터미널 기반의 인터페이스를 통해 개발자와 가장 밀접하게 호흡하는 도구입니다.

오늘은 제가 직접 Claude Code를 사용하며 정립한 기초 활용법부터 생산성을 극대화하는 팁들을 정리해 보았습니다.

---

## 1. 프로젝트 최적화의 시작: `CLAUDE.MD`

Claude Code를 실행했을 때 가장 먼저 챙겨야 할 것은 프로젝트의 맥락을 제공하는 것입니다.

### 프로젝트 초기화 및 컨텍스트 제공
루트 디렉토리에서 `claude init`을 실행하면 `CLAUDE.MD` 파일이 생성됩니다. 저는 이 파일에 프로젝트의 핵심 아키텍처, 코딩 컨벤션, 자주 사용하는 기술 스택을 명시하여 Claude가 환각 증상 없이 정확한 코드를 작성하도록 유도합니다.

```markdown
# CLAUDE.MD 예시
- Architecture: Next.js 15 App Router
- Logic: Server Actions 중심의 데이터 처리
- Style: Tailwind CSS v4 준수
```

### 효율적인 파일 참조 (`@`)
작업 중 특정 맥락을 강조하고 싶을 때는 `@` 기호를 활용합니다. `@파일명`으로 특정 로직을 짚어주거나, `@폴더명/`을 통해 전체적인 구조 분석을 요청할 수 있습니다.

---

## 2. 에이전트(Subagent)와 스킬(Skills) 확장

Claude Code의 진정한 매력은 사용자 입맛에 맞게 기능을 확장할 수 있다는 점입니다.

### 서브에이전트 정의
특정 도메인에 특화된 작업을 수행하도록 서브에이전트를 구성할 수 있습니다. 예를 들어, `~/.claude/agents/`에 코드 리뷰어 에이전트를 설정해두면 언제든 전문적인 리뷰를 받을 수 있습니다.

### 커스텀 스킬 활용
반복되는 지시사항이나 팀 내 복잡한 워크플로우를 스킬로 정의하면, Claude가 필요할 때마다 해당 로직을 로드하여 일관성 있는 작업을 수행합니다.

---

## 3. MCP(Model Context Protocol) 연동

MCP를 활용하면 Claude가 외부 도구와 직접 소통할 수 있습니다. Sentry 로그를 분석하거나 GitHub 이슈를 직접 읽어와 디버깅을 시작하는 등의 고도화된 작업이 가능해집니다.

```bash
# Sentry MCP 추가 예시
claude mcp add --transport http sentry https://mcp.sentry.dev/mcp
```

---

## 4. 생산성을 높이는 핵심 명령어 팁

제가 작업 효율을 높이기 위해 자주 사용하는 명령어들입니다.

- **/clear**: 새로운 태스크를 시작할 때는 반드시 이전 대화 내역을 지워 컨텍스트 오염을 방지합니다.
- **/compact**: 대화가 길어질 때 토큰 소모를 줄이기 위해 컨텍스트를 압축합니다.
- **권한 모드 조절**: 
    - `plan`: 분석만 수행하고 싶을 때 사용 (읽기 전용)
    - `acceptEdits`: 수많은 파일 변경을 일일이 승인하기 번거로울 때 활용

---

## 마치며: 도구는 곧 레버리지입니다

저는 항상 **"I don't just build software. I build leverage."**라는 철학을 가지고 있습니다. Claude Code는 단순히 코드를 작성해주는 비서가 아니라, 개발자가 아키텍처 설계와 비즈니스 로직 고민에 더 많은 시간을 할애할 수 있도록 돕는 강력한 '레버리지'입니다.

여러분도 `CLAUDE.MD`와 MCP 설정을 통해 여러분만의 최적화된 개발 환경을 구축해 보시기 바랍니다. 도구에 익숙해지는 시간을 투자할수록, 여러분의 개발 생산성은 기하급수적으로 늘어날 것입니다.
