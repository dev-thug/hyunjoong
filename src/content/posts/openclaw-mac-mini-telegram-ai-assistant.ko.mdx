# 오픈클로(OpenClaw)와 맥미니로 만드는 나만의 텔레그램 AI 비서

최근 AI 에이전트 기술이 급격히 발전하면서, 단순히 채팅창에서 대화하는 수준을 넘어 내 컴퓨터의 자원을 직접 활용하고 복잡한 작업을 수행하는 '퍼스널 에이전트'에 대한 수요가 늘고 있습니다. 

오늘은 집에 남는 **맥미니(Mac mini)**를 활용해, **오픈클로(OpenClaw)**를 설치하고 **Gemini CLI**를 연동하여 어디서든 **텔레그램**으로 명령을 내릴 수 있는 나만의 AI 비서를 구축하는 방법을 소개합니다.

---

## 왜 오픈클로(OpenClaw)인가?

오픈클로는 사용자의 로컬 환경(macOS, Linux 등)에서 실행되는 강력한 AI 에이전트 프레임워크입니다. 다음과 같은 강력한 장점이 있습니다:

1. **로컬 파일 및 도구 접근**: 내 맥에 있는 파일을 읽거나, 프로그램을 실행하고, 시스템 설정을 변경할 수 있습니다.
2. **다양한 채널 지원**: 텔레그램, 슬랙, 왓츠앱 등 평소 사용하는 메신저로 에이전트와 소통할 수 있습니다.
3. **확장성**: Python 스크립트나 CLI 도구를 '스킬(Skill)' 형태로 추가하여 기능을 무한히 확장할 수 있습니다.

---

## 준비물

시작하기 전에 다음 항목들이 준비되었는지 확인해주세요.

- **맥미니 (또는 macOS 기기)**: 상시 켜져 있는 서버 역할을 할 기기
- **Node.js**: v18 이상 추천
- **Google AI API Key**: Gemini 모델 사용을 위한 키 ([Google AI Studio](https://aistudio.google.com/)에서 발급)
- **텔레그램 봇 토큰**: [@BotFather](https://t.me/botfather)를 통해 생성

---

## 1단계: 오픈클로 설치하기

터미널을 열고 다음 명령어를 입력해 오픈클로를 설치합니다.

```bash
# npm을 통한 글로벌 설치
npm install -g openclaw

# 초기 설정 시작
openclaw init
```

설정 과정에서 워크스페이스 디렉토리를 지정하게 됩니다. 기본값으로 진행해도 무방합니다.

---

## 2단계: Gemini CLI 연동하기

오픈클로의 두뇌 역할을 할 LLM 모델을 설정합니다. 여기서는 가성비와 성능이 뛰어난 Gemini 모델을 사용합니다.

```bash
# Gemini API 키 설정
openclaw configure --section models
```

설정 메뉴에서 `google-gemini-cli`를 선택하고 발급받은 API 키를 입력합니다. 이제 오픈클로가 Gemini의 지능을 빌려 내 맥을 제어할 준비가 되었습니다.

---

## 3단계: 텔레그램 채널 연결하기

이제 외부에서도 맥미니에게 명령을 내릴 수 있도록 텔레그램 채널을 연동합니다.

```bash
# 채널 설정
openclaw configure --section channels
```

1. `telegram`을 선택합니다.
2. `Bot Token`에 @BotFather에게 받은 토큰을 입력합니다.
3. 보안을 위해 `Allowed User IDs`에 본인의 텔레그램 ID만 입력하는 것을 권장합니다.

---

## 4단계: 게이트웨이 실행

모든 설정이 완료되었다면 오픈클로 게이트웨이를 실행합니다.

```bash
# 게이트웨이 시작
openclaw gateway start
```

이제 텔레그램 봇에게 "안녕?"이라고 메시지를 보내보세요. 맥미니가 답장을 보낸다면 성공입니다!

---

## 실전 활용: 작업 위임하기

이제 텔레그램을 통해 다음과 같은 일들을 시켜볼 수 있습니다.

- **시스템 제어**: "지금 실행 중인 프로그램 알려줘", "휴지통 비워줘"
- **파일 작업**: "다운로드 폴더에 있는 최신 PDF 파일 요약해줘"
- **정보 조사**: "내일 강남역 근처 날씨 어때? 우산 챙겨야 할까?"
- **블로그 포스팅**: "오늘 공부한 내용을 바탕으로 기술 블로그 초안 써줘"

---

## 마치며: 시스템의 확장성, Leverage를 만들다

저는 단순히 소프트웨어를 만드는 것에 그치지 않고, **레버리지(Leverage)**를 만드는 것을 중요하게 생각합니다. 맥미니와 오픈클로를 결합한 이 시스템은 저의 시간을 아껴주는 강력한 레버리지가 되어주고 있습니다.
