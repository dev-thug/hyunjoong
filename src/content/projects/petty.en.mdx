## Conversations that become stories

Petty lets people discover characters across romance, fantasy, contemporary fiction, and science fiction, then become the protagonist of their own conversations. Discovery and returning to a saved conversation form one product journey.

## Features

- **Discovery:** Choose characters by interest and genre
- **Roleplay:** Continue stories using character and conversation context
- **History:** Save and revisit conversations
- **Streaming:** Display replies as they are generated

## Engineering

The hybrid app combines a Next.js static export with Capacitor. AWS Amplify Gen2 provides data and authentication. TanStack Query and Zustand separate server state from UI state.

A Lambda-based SSE endpoint handles chat authentication and conversation ownership before streaming model responses. Amplify Data persists messages, while the UI connects saved history with the current reply.
