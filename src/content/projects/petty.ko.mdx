## 대화가 다음 이야기로 이어지는 경험

페티는 로맨스·판타지·현대·SF 등 다양한 캐릭터를 만나고, 사용자가 주인공이 되어 이야기를 이어가는 제품입니다. 캐릭터를 고르는 순간부터 대화 이력을 다시 여는 흐름까지 하나의 경험으로 설계했습니다.

## 주요 기능

- **캐릭터 탐색:** 취향과 장르에 맞는 캐릭터 선택
- **대화와 역할극:** 캐릭터 설정과 대화 맥락을 바탕으로 이야기 전개
- **이어지는 기록:** 대화 이력을 저장하고 다시 확인
- **스트리밍 응답:** 생성되는 답변을 순차적으로 표시

## 구현 구조

Next.js 정적 출력과 Capacitor를 결합한 하이브리드 앱입니다. AWS Amplify Gen2가 데이터·인증 기반을 제공하며, TanStack Query와 Zustand로 서버 상태와 화면 상태를 나눠 관리합니다.

채팅은 Lambda 기반 SSE 경로를 사용합니다. 서버에서 인증과 대화 소유권을 확인하고 모델 응답을 스트리밍하며, 메시지 이력은 Amplify Data에 저장합니다. 화면은 저장된 이력과 진행 중인 응답을 연결합니다.
