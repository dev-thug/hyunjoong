**AI 기반 한의원 전자차트(EMR) 시스템**

예진은 한의원의 진료 기록과 처방 보조 흐름을 디지털화한 EMR 시스템입니다. 클리닉별 데이터 격리, 사용자 권한, 진료 데이터 액세스 패턴을 중심으로 프론트엔드부터 AWS 백엔드와 배포 구조까지 구현했습니다.

## 주요 구현

- **진료 기록 UI:** React와 TypeScript로 환자·진료 기록 흐름과 처방 보조 인터페이스 구현
- **멀티테넌트 인증:** AWS Amplify Gen1과 Cognito로 클리닉별 사용자·권한 경계 구성
- **데이터 격리:** 클리닉·환자·진료 기록 액세스 패턴을 기준으로 DynamoDB 키 설계
- **GraphQL API:** 필요한 진료 데이터를 중심으로 쿼리와 응답 범위를 정리
- **서버리스 백엔드:** Lambda에서 API와 처방 보조 로직을 실행
- **인프라 코드화:** CloudFormation으로 환경과 배포 구성을 관리

## Technical Architecture

**1. Frontend & Auth**

- **ReactJS · TypeScript:** 전자차트 UI와 처방 보조 인터페이스
- **AWS Amplify Gen1:** 멀티테넌트 애플리케이션 구성
- **Cognito:** 사용자 인증 및 권한 관리

**2. Backend & Data**

- **Lambda · GraphQL:** API와 처방 보조 로직
- **DynamoDB:** 액세스 패턴 기반 키 설계와 클리닉별 데이터 경계
- **CloudFormation:** 인프라 코드화 및 배포 자동화

## Key Technologies

ReactJS, TypeScript, AWS Amplify Gen1, Lambda, DynamoDB, GraphQL, Cognito, CloudFormation
