# Healicure - 예진 (Yejin Clinic)

**AI 기반 한의원 전자차트(EMR) 시스템**

한의사 전용 AI 처방 추천 EMR 시스템으로, 환자 증상 입력 시 AI가 실시간 처방을 추천합니다. AWS Amplify Gen1 기반 멀티테넌트 인증 구조와 DynamoDB 액세스 패턴 최적화로 초진 시간을 27분에서 12분으로 단축했습니다.

## 💡 주요 성과

- **초진 시간 단축:** AI 처방 추천으로 초진 시간 27분 → 12분 (**55% 단축**)
- **TIPS 선정 기여:** 베타 테스터 3곳, 30건 초진 로그 측정 데이터로 TIPS 선정(2023.05)에 기여
- **GraphQL 최적화:** 쿼리 최적화로 네트워크 오버헤드 **60% 감소**
- **DynamoDB 키 설계:** 액세스 패턴 분석 기반 키 설계 최적화
- **멀티테넌트 인증:** Amplify Gen1 기반 멀티테넌트 인증 구조 구현

## 🏗 Technical Architecture

**1. Frontend & Auth**

- **ReactJS · TypeScript:** 전자차트(EMR) UI 및 실시간 AI 처방 추천 인터페이스
- **AWS Amplify Gen1:** 멀티테넌트 인증 구조, 클리닉별 데이터 격리
- **Cognito:** 사용자 인증 및 권한 관리

**2. Backend & Data**

- **Lambda · GraphQL:** API 및 AI 처방 추천 로직, 쿼리 최적화로 오버헤드 60% 감소
- **DynamoDB:** 액세스 패턴 분석 기반 키 설계, 일관된 저지연 조회
- **CloudFormation:** 인프라 코드화 및 배포 자동화

## 🛠 Key Technologies

ReactJS, TypeScript, AWS Amplify Gen1, Lambda, DynamoDB, GraphQL, Cognito, CloudFormation
