# Topic selection playbook

Use recent conversation context as signal for what the user cares about.

Prioritize topics that connect to themes already discussed:
- AI agents and orchestration
- cron automation and autopublishing
- review/test/CI automation
- MCP and tool integrations
- model-vs-system tradeoffs

Selection steps:
1. Extract recurring themes from user context.
2. Turn themes into candidate post ideas.
3. Score each candidate for relevance, novelty, and practicality.
4. Pick the highest-scoring idea that can become a sharp post.
5. Draft in Korean first, then English.

Scoring rubric:
- 3 = strongly aligned with the user's current interests
- 2 = related but broader
- 1 = weak fit
- 0 = not a fit

Prefer posts that can be written with a clear recommendation and a concrete takeaway.
