(주)웅진 | AWS Cloud Architect

김현중

저는 4년간 스타트업에서 AWS 서버리스·이벤트 기반 아키텍처를 설계/운영하며, 대규모 데이터 처리 파이프라인을 단일 EC2 구조에서 AWS Batch 중심 구조로 전환해 월 인프라 비용을 600만 원 → 50만 원 수준(약 92%↓)으로 낮추고, 분석 처리 시간은 30분 → 10분(3배 향상)으로 개선했습니다. 또한 Terraform/CloudFormation 기반 IaC와 모니터링 자동화(CloudWatch·알림)를 통해 운영 리스크를 줄였고, Bedrock 기반 LLM Agent 프로젝트로 명세→작업 분해→코드/테스트/문서화 전 과정에 AI를 내재화해 개발 생산성을 70% 이상 향상시킨 경험이 있습니다.

웅진이 다양한 산업군 고객사에 제공하는 클라우드 전환·운영 효율화·보안 강화 미션을, "비용/속도/안정성"으로 증명해 온 방식으로 즉시 기여하겠습니다.

1. Architecture & FinOps, 아키텍처 개선으로 비용 최적화

유전체 분석 플랫폼에서 1,000개 이상의 샘플을 동시에 처리해야 했고, 초기 단일 EC2 구조는 트래픽 변동에 취약하며 유휴 시간에도 비용이 고정 발생하는 문제가 있었습니다. 저는 "필요할 때만 쓰고, 자동으로 확장되는 구조"로 전환하기 위해 Managed Service 중심의 서버리스 아키텍처로 재설계했습니다.

  • 컴퓨팅 구조 전환: 상시 가동 EC2 대신 AWS Batch 기반 작업 실행으로 전환해, 작업량에 맞춰 리소스를 탄력적으로 사용하도록 구성
  • 데이터 처리 병목 대응: 대용량 참조 데이터(약 10GB)를 공유하기 위해 EFS를 마운트하여 컨테이너 간 공유를 최적화
  • 이벤트 기반 비동기 분리: EventBridge + SNS/SQS로 "실시간 요청/상태"와 "장기 배치 작업"을 분리해 안정성 확보
  • 운영 관점 개선: 병렬 처리 확장 시 발생한 I/O 스로틀링을 CloudWatch로 관측하고, 다중 EFS 분산/로드밸런싱 방향으로 개선안을 설계

이 경험은 웅진이 수행하는 클라우드 이관/전환 및 비용 최적화(운영 효율) 과제에서, 고객사별 워크로드 특성을 분석하고 비용 구조를 바꾸는 아키텍처 의사결정으로 바로 재현할 수 있습니다.

2. Security, 사용자별 데이터 격리/권한 통제를 구조적으로 구현

의료/민감 데이터 성격의 서비스에서 테넌트 단위 인증·인가와 데이터 분리는 필수였습니다. 저는 보안을 "운영 단계의 옵션"이 아니라 "설계 단계의 기본값"으로 두고 구조를 만들었습니다.

  • 인증/인가: AWS Cognito 기반으로 사용자/역할 권한을 분리하고, 테넌트 단위 접근 제어를 설계
  • 데이터 격리: DynamoDB 모델링 단계에서부터 테넌트 키를 중심으로 논리적 파티셔닝을 적용해 데이터 경계를 명확히 구성
  • 보안 운영: 모니터링/알림 체계를 통해 이상 징후를 빠르게 감지할 수 있도록 운영 흐름을 정리

SSL/VPN/데이터 보안 등 보안 기술을 활용한 안전한 시스템 구축에 대해, 저는 "권한/데이터 경계/운영 감시"를 한 세트로 설계해본 경험을 기반으로 고객사의 보안 요구를 충족시키겠습니다.

3. DevOps & Automation, IaC/자동화 도입으로 반복 비용을 축소

스타트업 환경에서는 인프라 변경과 배포가 잦았고, 수동 작업은 장애와 지연의 원인이 되었습니다. 저는 인프라를 코드로 관리하고(재현 가능), 관측 가능성을 높여(원인 파악), 운영을 자동화하는(복구/알림) 방향으로 체계를 만들었습니다.

  • IaC: Terraform/CloudFormation으로 핵심 리소스를 코드화해 환경 재현과 변경 이력을 관리
  • 관측 가능성: CloudWatch 기반 로그/메트릭을 정리하고 알림 연동으로 장애 탐지 시간을 단축
  • 운영 자동화: 이벤트 기반 비동기 파이프라인에서 DLQ, 재시도 정책을 함께 설계해 장애 전파를 줄임

운영/모니터링, DevOps 및 자동화 도입에 맞춰, 고객사 환경에서도 표준화된 IaC + CI/CD + 모니터링 구성으로 운영 효율과 안정성을 동시에 끌어올리겠습니다.

4. New Tech & AI, LLM을 개발 전 과정에 통합

최근 개인 프로젝트 Specify.app에서 AWS Bedrock 기반 LLM Agent를 설계·구현했습니다. 핵심은 AI를 단순 기능이 아니라, 문맥을 유지하며 사용자의 의도를 추론하고 "다음 단계"를 제안하는 워크플로우로 만드는 것이었습니다.

  • 아키텍처: Next.js + Amplify Gen2/AppSync로 빠르게 실험 가능한 구조를 잡고, 문맥 유지/이력 반영을 고려한 Agent 형태로 구성
  • 업무 적용 방식: LLM을 명세 구체화 → 작업 분해 → 코드 작성·테스트·문서화 전 과정에 내재화해 생산성을 체감 수준으로 개선

GPT/Amazon Q 등 AI 기술 관심을 "관심"이 아니라 실제 적용 경험과 프로세스 혁신으로 증명할 수 있습니다. 또한 AI 도입 시 비용/보안/운영 관점(거버넌스·관측 가능성)까지 함께 고려하여, 기업 고객 환경에서도 안정적으로 확장 가능한 형태로 제안하겠습니다.

5. 웅진IT에서

웅진은 20년간 다양한 산업군의 IT 컨설팅 경험과 클라우드 전환 역량을 바탕으로, 고객사에 맞춤형 Total IT Service를 제공하며 디지털 전환을 선도하고 있습니다. 저는 스타트업에서 "빠르게 구축하고 끝"이 아니라, 운영 비용 구조를 바꾸고(92% 절감), 성능을 개선하고(3배), 안정적으로 운영하는 구조를 만들어 왔습니다. 이 방식은 웅진의 고객사 환경에서도 가장 직접적인 가치(비용·속도·안정성)로 이어질 수 있다고 확신합니다.

저는 설계를 문서로 끝내지 않고, 실제 운영 결과로 증명하는 Actionable Architect로서 웅진의 클라우드 혁신을 함께 만들겠습니다.
