콘텐츠 IP 금융 솔루션의 혁신을 이끌
풀스택 개발자, 김현중

에버트레져의 콘텐츠 IP 금융 솔루션과 에버씰(EverSeal) 개발에 기여하고 싶습니다. 콘텐츠 IP를 금융 자산으로 전환하고, 블록체인 기반 NFT와 NFC 기술을 통해 진위성을 보장하는 혁신적인 서비스는 디지털 콘텐츠 산업의 새로운 패러다임을 만들어가고 있습니다. 4년간 스타트업에서 React/Next.js, TypeScript 기반 프론트엔드와 Python/Django 백엔드를 개발하며 풀스택 역량을 쌓아온 저는, 에버트레져의 기술 스택과 완벽히 부합하는 경험을 보유하고 있습니다. 특히 NestJS/TypeScript 기반 백엔드 개발, AWS/GCP 클라우드 인프라 구축, CI/CD 파이프라인 설계 경험은 에버씰 개발과 웹 서비스 운영에 직접적으로 기여할 수 있습니다.

React/Next.js와 TypeScript 기반 사용자 친화적 웹 프론트엔드 개발

예진 서비스 프로젝트에서 ReactJS와 TypeScript를 활용해 한의사 전용 AI 기반 EMR 웹 서비스를 단독 개발했습니다. GraphQL API를 최적화하여 네트워크 오버헤드를 60% 줄이고, 사용자 인터페이스를 모바일 친화적으로 설계하여 진료 시간을 55% 단축(27분에서 12분으로)하는 성과를 달성했습니다. 최근 Specify.app 개인 프로젝트에서는 Next.js 16과 TypeScript를 활용해 AI 기반 협업 문서 편집 플랫폼을 구축하며, 실시간 Subscription과 Stateful Context 설계로 사용자 경험을 최적화했습니다. 이러한 경험은 에버트레져의 웹 서비스에서 사용자들이 콘텐츠 IP를 투자하고 관리하는 과정을 직관적이고 효율적으로 만들어가는 데 기여할 수 있습니다.

Python/Django 백엔드 API 개발 및 아키텍처 설계

유전체 분석 플랫폼 프로젝트에서 Python을 활용한 대용량 데이터 처리 시스템을 개발했습니다. AWS Batch와 EFS를 통합한 병렬 처리 시스템을 설계하여 1,000개 이상의 샘플 데이터를 효율적으로 연산함으로써 처리 시간을 66% 단축(30분에서 10분으로)하고, 서버리스 전환을 통해 월간 인프라 비용을 92% 절감(600만 원 규모)하였습니다. EventBridge와 SNS/SQS 기반 이벤트 드리븐 아키텍처를 구현하여 실시간 요청과 장시간 배치 작업을 안정적으로 분리했습니다. Python 기반 백엔드 개발 경험과 RESTful API 설계 역량은 에버트레져의 Django 백엔드 API 서버 개발 및 아키텍처 설계에 직접적으로 활용할 수 있습니다.

MySQL RDBMS 스키마 설계 및 쿼리 최적화

예진 서비스와 유전체 분석 플랫폼에서 DynamoDB NoSQL 데이터 모델링을 통해 UX 데이터 액세스 패턴을 분석하고 키 디자인을 최적화했습니다. 멀티테넌트 구조를 구현하며 데이터 격리와 권한 관리에 대한 깊은 이해를 쌓았습니다. 이러한 경험을 바탕으로 MySQL 등 RDBMS의 스키마 설계, 정규화, 인덱싱 전략을 수립하고, 복잡한 쿼리를 최적화하여 성능을 향상시킬 수 있습니다. 에버트레져의 콘텐츠 IP 금융 솔루션에서 사용자 정보, 투자 내역, 콘텐츠 메타데이터 등을 효율적으로 관리하는 데이터베이스 구조를 설계하고 운영하는 데 기여하겠습니다.

NestJS/TypeScript 기반 백엔드 개발 및 블록체인 통합

유전체 분석 플랫폼에서 NestJS와 TypeScript를 활용한 백엔드 API를 개발하고 유지보수했습니다. AppSync/GraphQL을 통해 실시간 상태 추적을 구현하고, Lambda 기반 서버리스 아키텍처로 확장 가능한 시스템을 구축했습니다. 이러한 경험은 에버씰(EverSeal)의 NestJS/TypeScript 기반 백엔드 API 개발에 직접적으로 활용할 수 있습니다. 특히 XRPL(XRP Ledger) 블록체인 NFT 민팅/소각 기능 개발과 NFC CMAC 서명 검증 로직 구현은 새로운 도전이지만, 제가 지금까지 쌓아온 이벤트 드리븐 아키텍처 설계 경험과 외부 API 연동 역량을 바탕으로 빠르게 학습하고 구현할 수 있습니다. Android 앱(Kotlin/Jetpack Compose)과의 API 연동 경험은 없지만, RESTful API 설계 원칙과 인증/권한 관리 경험을 통해 효율적으로 연동할 수 있습니다.

AWS/GCP 클라우드 인프라 및 CI/CD 파이프라인 구축

유전체 분석 플랫폼에서 AWS 서버리스 아키텍처를 설계하고 운영했습니다. Amplify Gen2, AWS Batch, SQS, Lambda, DynamoDB, Cognito 등을 활용한 Event Driven 아키텍처를 구현하여 대규모 트래픽을 안정적으로 처리했습니다. CloudFormation과 Terraform을 활용한 IaC 자동화로 인프라 배포를 표준화하고, CloudWatch와 APM 솔루션을 통한 실시간 모니터링 체계를 구축하여 7×24 운영 안정성을 확보했습니다. 예진 서비스에서는 CloudFormation으로 인프라 배포를 자동화하고, ELK 스택으로 로그 모니터링을 구현하여 장애 원인 분석 시간을 50% 단축했습니다. 이러한 경험은 에버트레져의 AWS, GCP 클라우드 환경에서의 서비스 배포 및 운영, 그리고 Github Action, Jenkins, Argo CD 등을 활용한 CI/CD 파이프라인 구축에 직접적으로 기여할 수 있습니다.
