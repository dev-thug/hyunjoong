데이터라이즈의 이커머스 CRM 혁신을 책임질 백엔드 개발자,
김현중

데이터라이즈의 백엔드 챕터에 합류해 'Data Makes Growth' 미션을 실현하고 싶습니다.4년간 스타트업에서 서버리스 아키텍처를 설계하며 대용량 데이터 처리와 운영 효율을 높인 경험을 바탕으로, 메시지/온사이트 서비스의 파이프라인, 결제 시스템, 진단 지표 시각화, 인프라 확장을 기여하겠습니다.

1. 대용량 데이터 처리와 인프라 안정성을 확보하며 확장성을 고려한 경험

인간 유전체는 약 30억 개의 염기쌍으로 구성되어 있으며, 이를 시퀀싱한 raw 데이터는 보통 100~200GB 규모입니다. 수천 개 이상의 샘플을 처리할 경우 데이터 크기는 테라바이트에서 페타바이트 단위로 확장됩니다. 이러한 특성으로 인해 분석 과정에서는 높은 I/O 성능과 병렬 연산 효율이 요구됩니다. 따라서 효율적인 데이터 파이프라인 설계와 안정적인 인프라 운영이 핵심 과제로 이어집니다. 이에 따라 유전체 분석 앱을 개발하며 AWS Batch와 EFS를 활용해 대규모 데이터 처리 안정성을 확보했습니다. 10GB 참조 데이터를 EFS에 마운트하고, 병렬 컴퓨팅을 설계해 1000개 샘플을 동시에 연산할 수 있게 했습니다. 처리 시간을 30분에서 10분으로 단축해 비용과 성능을 개선했습니다. 데이터라이즈의 인프라/진단 업무처럼 대용량 처리 방법을 고민하며, 1000명 동시 처리 시 트래픽 문제를 사전 모니터링했습니다. 그러나 프로젝트 진행 중 1000개의 Fargate 인스턴스가 단일 EFS 파일시스템에 동시에 접근하면서 EFS 처리량 한계에 도달해 I/O 스로틀링이 발생한 경험이 있습니다. 이를 통해 대규모 병렬 처리 시 I/O 병목이 주요 장애 요인임을 학습하였고, 멀티 EFS 분산 구성과 로드밸런싱 설계를 통해 개선 방안을 마련 하였습니다. 또한 기존의 단일 EC2 기반 시스템을 AWS Batch로 전환하여 확장성과 안정성을 높였으며, AWS Cognito를 도입해 데이터 접근 보안을 강화했습니다. 이러한 경험을 통해 대용량 데이터 처리와 안정적 인프라 운영 역량을 키웠으며, 데이터라이즈의 대규모 데이터 제공 기술 연구에 실질적으로 기여할 수 있다고 생각합니다.

2. 이벤트 기반 서비스 구조 및 메시징 신뢰성 확보 경험

유전체 분석 플랫폼에서는 실시간 사용자 요청과 장시간 배치 분석 작업이 동시에 발생하는 구조였습니다. 기존 시스템은 요청 수가 몰릴 경우 API가 지연되거나 분석 작업이 중단되는 문제가 있었고, 이는 의료 데이터 처리 특성상 단 한 번의 장애도 신뢰 손상으로 이어질 수 있는 상황이었습니다. 또한 오류 발생 시 로그 추적이 어렵고, 장애 원인 확인에 시간이 많이 소요되어 운영 부담도 컸습니다. 이 문제를 해결하기 위해 이벤트 기반 비동기 아키텍처로 구조를 전환했습니다. 서비스 간 이벤트 흐름을 EventBridge로 라우팅하고, SNS·SQS 기반 큐 처리로 요청을 분리하여 실시간 트래픽과 분석 작업이 서로 영향을 주지 않도록 설계했습니다. DLQ와 CloudWatch 알림을 구성해 실패 이벤트를 자동 추적하고, Lambda 자동 스케일링으로 트래픽 변동에 유연하게 대응했습니다. 그 결과, 장애 원인 추적 시간이 절반 이하로 줄었고, 갑작스러운 트래픽 발생 시에도 서비스 중단 없이 안정적으로 요청을 처리할 수 있었습니다. 이 경험을 바탕으로 데이터라이즈의 메시지·온사이트 개인화 파이프라인에서도 실시간성·안정성·확장성을 보장하는 아키텍쳐 설계에 기여하겠습니다.

3. 고객 니즈를 깊이 이해하고 복잡한 문제를 능동적으로 해결한 경험

예진 서비스 프로젝트는 한의사 전용 AI 기반 EMR 웹 서비스로, 환자 증상을 입력하면 AI가 처방을 추천해 진료 효율을 높입니다. 한의사들은 진료 프로세스의 수동 입력으로 평균 초진 27분이 소요되고, 환자 데이터 관리 비효율, 처방 추천 부재로 임상 판단에만 의존했습니다. 초기 세팅부터 배포까지 주도하며 고객(한의사) 피드백을 실시간 반영했습니다. ReactJS로 인터랙티브 UI를 구현해 증상 입력에서 처방 추천 흐름을 직관화했고, AWS Amplify Gen1 기반 Event-Driven 아키텍처로 API 호출 모듈을 최적화했습니다. DynamoDB 데이터 액세스 패턴을 분석해 테이블·키를 설계하고, GraphQL로 필요한 데이터만 패칭해 네트워크 오버헤드를 60% 줄였습니다. 베타 테스터 한의원·보건소 3곳에서 30건 초진 로그를 측정해 27분에서 12분으로 55% 단축을 달성했으며, 이 프로덕션급 안정성 덕분에 TIPS 프로그램(2023.05) 선정에 기여했습니다. 이 경험을 통해 데이터라이즈의 개인화 콘텐츠 전달 파이프라인을 안정적이고 유연하게 설계하겠습니다.

4. 팀 플레이와 코드 리뷰를 통해 공유와 성장을 추구한 경험

Fortuna Helix에서 테크 리더로 활동하며 주간 코드 리뷰 세션을 운영했습니다. 리뷰 기준은 성능 최적화와 안정성에 두었으며, 특히 서버리스 환경의 비동기 처리 로직과 응답 지연 가능성을 중점적으로 검토했습니다. 그 과정에서 동료 코드에서 비동기 함수 호출 타이밍에 따라 잠재적으로 에러가 발생할 수 있는 구간을 식별하고, 처리 패턴을 개선해 응답 속도 및 안정성을 향상한 경험이 있습니다. 단순한 코드 지적이 아니라, 성능 개선 방향과 대안을 함께 제안하는 방식으로 피드백을 진행했습니다. 또한 코드 리뷰는 단순 품질 검토가 아니라 서로 다른 개발 기준을 맞춰가는 협업 과정이라고 생각했습니다. 리뷰를 준비하며 제 코드의 근거를 설명할 수 있을 만큼 깊이 이해하려 노력했고, 동료의 코드 또한 충분히 탐구하며 학습했습니다. 자연스럽게 팀 내 학습 문화가 형성되었고, 리뷰가 “지적”이 아닌 함께 성장하는 루틴으로 자리잡았습니다. 데이터라이즈 역시 투명한 협업과 동료 존중의 문화가 강하다고 이해하고 있습니다. 같은 철학 아래, 코드 리뷰와 기술 공유를 통해 팀 생산성을 높이고 팀원들과 함께 성장하는 개발 문화를 만들어가겠습니다.

가파르게 성장하는 데이터라이즈 백엔드 챕터의 일원으로서, 확장성과 유지보수성을 갖춘 시스템을 구축하고 팀의 개발 생산성을 높이겠습니다. 대규모 실서비스 환경에서 발생하는 문제를 기회로 삼아 빠르게 학습하고, 기술과 서비스 이해도를 폭넓게 확장할 준비가 되어 있습니다. 팀과 함께 더 빠르게 성장하며, 새로운 기술적 도전과 기회를 마주할 때 가장 먼저 나서서 해결하는 사람이 되겠습니다.

  • 기술 스택: Amplify Gen2 (웹 인터페이스), AWS Batch (병렬 처리, Max CPU 20,000), ECR (컨테이너 이미지), S3 (파일 저장), EFS (참조 파일 공유), SQS (메시지 큐), Lambda (비즈니스 로직), DynamoDB (데이터 저장), Cognito (인증), CloudFormation (IaC), Node.js (백엔드 운영), ELK (모니터링 대체로 SNS/AppSync 사용). Python 스크립트 멀티쓰레드.
  • 프로젝트 전후 개선점: 이전 수동 순차 처리(30분/샘플, 고비용 EC2 운영)에서 Event Driven 병렬 컴퓨팅으로 전환, 분석 시간 30분→10분(66% 단축), 운영 비용 600만→50만 절감. 실시간 상태 추적(SNS/AppSync) 추가로 사용자 경험 향상; EFS 최적화로 10GB 참조 파일 공유 문제 해결(ECR/S3 비교 테스트 후 선택). 실패 학습: EFS 쓰로틀링 (멀티 EFS 로드밸런싱 계획). 확장성과 안정성 제공.

예진 서비스 (헬리큐어, yejin.clinic, 2021.12–2023.12)

  • 역할: 백엔드 개발자로서 백엔드/프론트엔드 단독 개발, Infra 구성, 보안/API/UI 개발, 유지보수 주도.
  • 기술 스택: ReactJS (프론트엔드 UI/UX), Node.js (백엔드 API), AWS Lambda (API 운영), DynamoDB (NoSQL 모델링), Cognito (보안), SES/Jira API (자동화), CloudFormation (Infra), ELK (로그 모니터링), ORM (초기 ORM에서 NoSQL 전환).
  • 프로젝트 전후 개선점: 초기 수동 진료 프로세스(시간 지연, 오류 발생)에서 ReactJS 기반 직관적 UI와 Lambda 자동화로 전환, 진료 시간 20% 단축, TIPS 선정(2023.05) 기여. SES/Jira로 업무 자동화(생산성 30%↑), 멀티테넌트 보안 구조로 데이터 보호 강화. 서비스 런칭부터 유지보수로 안정적 운영 달성. 퍼포먼스: 병렬 스텝 비동기 스트리밍/백프레셔.
