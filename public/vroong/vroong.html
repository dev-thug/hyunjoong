부릉의 플랫폼 팀에 합류해 '넥스트 부릉' 미션을 실현하고 싶습니다. 4년간 스타트업에서 서버리스 아키텍처를 설계하며 대용량 데이터 처리와 운영 효율을 높인 경험을 바탕으로, 이 미션에 최신 기술을 적용해 팀 생산성을 극대화하겠습니다

1. 부릉의 기술 도약을 만들어낼 준비가 된 엔지니어

서버리스 환경에서 멀티테넌트 기반 대규모 배치·실시간 이벤트 시스템을 설계하며, 프론트엔드부터 백엔드까지 전 영역을 다루는 풀스택 엔지니어 김현중입니다. 스타트업에서 4년간 TypeScript와 Node.js 기반 서버 개발, React 프론트엔드 구축, AWS 서버리스 아키텍처 설계를 통해 대규모 데이터를 안정적이고 확장성 있게 처리한 경험을 보유하고 있습니다.
특히 1,000개 이상의 동시 샘플 데이터를 처리하는 유전체 분석 플랫폼에서는 AWS Batch와 EFS를 활용한 병렬 처리 설계를 통해 처리 시간을 30분에서 10분으로 단축하고, 단일 EC2 구조에서 서버리스로 전환하며 월 600만 원의 비용 절감 효과를 달성했습니다. 이 경험은 부릉의 혁신적인 라스트마일 물류 플랫폼에서도 안정적이고 확장 가능한 시스템을 설계하고 운영할 수 있는 기반이 될 것입니다.

2. Cloud Native 아키텍처 설계와 구현

Multi-tenant 구조를 기반으로 한 서버리스 아키텍처 설계 경험을 가지고 있습니다. 예진 서비스 프로젝트에서는 Amplify 기반 멀티테넌트 인증과 GraphQL API 구현하며, DynamoDB를 활용한 데이터 모델 최적화로 UX 데이터 접근 속도를 높였습니다. 이를 통해 사용자별 데이터 분리와 권한 관리, 보안 강화까지 동시에 달성했습니다. 또한, 유전체 분석 플랫폼에서는 EventBridge, SNS, SQS를 활용한 이벤트 기반 비동기 아키텍처를 구축하여 실시간 요청과 장시간 배치 처리를 동시에 안정적으로 수행했습니다. 장애 발생 시 DLQ와 CloudWatch 알림을 통해 자동 모니터링을 구현했고, Lambda 재시도 및 병렬 처리 최적화를 통해 엔터프라이즈급 안정성을 확보했습니다. 이러한 경험을 통해, 부릉에서 필요로 하는 보안, 성능, 안정성을 모두 갖춘 엔터프라이즈급 풀스택 시스템 설계 역량을 확보했습니다.

3. 경험을 바탕으로 새로운 도전

새로운 기술을 학습하고 도전 한 경험은 제가 설계하고 개발한 Specify.app입니다. 이 사이드 프로젝트는 단순히 문서 편집 툴을 만드는 것이 아니라, Notion의 문서 관리, Cursor IDE의 AI 기반 편집, Obsidian의 지식 연결 구조를 하나의 AI-first 경험으로 통합하는 것을 목표로 했습니다. 저는 이 전체 구조를 혼자 설계하고 빠르게 반복 개발하며, AI를 서비스 전반의 핵심 워크플로우에 녹여내는 경험을 쌓았습니다. 초기 아이디어만 있었던 상태에서 바로 프로토타입을 만들기 위해 Next.js 15, Amplify Gen2, AppSync, CodeMirror를 선택했고, 문서 협업을 위해 Y.js 기반 CRDT 엔진을 적용했습니다. Y.Doc과 CodeMirror를 연결하고, Y.js 변경 스트림을 AppSync Subscription과 연동하여 실시간 동기화를 구현했습니다. 중간에 충돌 병합과 지연 누적 문제도 발생했지만, 작은 단위 기능을 빠르게 반복 개발하며 해결했습니다. 이 과정은 부릉이 중요하게 여기는 속도와 실행력, 소규모 팀 단위의 빠른 반복이라는 개발 철학과 정확히 일치했습니다.
또한 이 프로젝트의 핵심인 AI 부분은 Amplify Gen2 Bedrock 기반의 LLM 을 사용하여 에이전트로 구현했습니다. 단순히 조언을 주는 AI가 아니라, 문서 흐름과 작성 의도를 기억하고 구체화하여 사용자가 글을 발전시킬 수 있도록 돕는 AI 편집 파트너를 목표로 했습니다. 이를 위해 문맥 유지, 사용자 의도 추론, 이전 편집 이력 반영 등 AI Agent 중심 Interaction 설계를 수행했습니다. 이 프로젝트를 통해 AI 기능을 서비스의 메인 프로세스로 자연스럽게 통합하는 설계 능력, 실시간 협업 및 문맥 유지와 같은 난이도 높은 문제를 빠르게 실험하고 해결한 실행력, 사용자별 문서 공간을 분리한 멀티테넌트 유사 구조에 대한 이해, 그리고 프론트, 백엔드, AI, 클라우드를 모두 아우르는 풀스택 구현 역량을 실질적으로 체득할 수 있었습니다. AI 모델이 단순 인터페이스가 아니라 서비스 구조 자체를 변화시키는 경험을 만들어보며, 부릉의 GenAI 중심 서비스 개발 방식이 제게 매우 자연스럽고 즐거운 방식이라는 확신을 얻었습니다. 부릉에서도 같은 방식으로 빠르게 실험하고, AI 기반 기능을 통해 서비스 완성도를 한 단계 끌어올리는 역할을 하고 싶습니다.

저는 클라이언트와 서버에 대한 이해와 클라우드 활용까지 아우르는 경험을 갖춘 개발자입니다. 웹,백엔드, 클라우드 전반의 시스템 설계 및 개발, 엔터프라이즈급 안정성, 클라우드 영역에 실무 경험과 실적이 있습니다. '넥스트 부릉'을 함께 만들어가며, 안정적이면서도 혁신적인 서비스를 설계하고 운영하는 Fullstack Engineer로 기여하고자 합니다.
